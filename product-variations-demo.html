Weight / size options appear directly on every product card. Shoppers pick a variant and tap Add to Cart without leaving the shop listing page — reducing friction and improving conversion especially on mobile.

How it works: Chips are generated server-side (PHP) from WooCommerce variation data and embedded as data-variations JSON on the card. On selection the matching variation_id is resolved client-side, the price updates instantly, and the Add to Cart fires a WooCommerce AJAX request — no page reload required. The 500g chip above shows the out-of-stock state (strikethrough, disabled).
Implementation Plan — 3 Files

⚙️ functions.php

  • Hook woocommerce_after_shop_loop_item (priority 8) to render chips for variable products
  • Filter woocommerce_loop_add_to_cart_link to replace "Select options" with a disabled Add to Cart button for variable products
  • Embed data-variations JSON (variation_id, attributes, price, stock) on wrapper element
  • Uses $product->get_available_variations() — safe for small catalogs

🎨 style.css

  • Chip / pill styles matching brand orange #CE6621
  • Selected state: filled orange background
  • Out-of-stock state: strikethrough + 40% opacity, pointer disabled
  • Disabled Add to Cart: muted gray, re-enabled on selection
  • Loading and "Added ✓" green feedback states
  • Fully responsive — chips wrap on narrow cards

⚡ custom.js

  • Chip click: deselects siblings in group, marks clicked chip .selected
  • Resolves matching variation_id from embedded JSON using selected attribute values
  • Updates displayed price instantly (no server round-trip)
  • Enables Add to Cart button only when a valid in-stock variation is matched
  • AJAX add-to-cart via wc_add_to_cart_params.ajax_url
  • Button shows loading spinner → "✓ Added" → resets after 2 s
